Diagnostics

Catch broken modules in the Studio UI

Run Diagnostics checks the active editor buffer and related project files without writing to disk. The console shows severity, file, line, and a focused message.

Diagnostics
error | main.lua:41 | main.lua must end by returning the module table.
warning | main.lua:9 | Unknown module hook: on_render_world
warning | module.json:6 | Marketplace metadata should include author.

Checks

What it catches

The pass looks for missing return module, unbalanced function/end blocks, unsafe host tokens, unknown hooks, malformed JSON, duplicate settings, empty settings, missing metadata, and missing docs links.

main.lua
module.json
settings.json

Read-only pass
No save required
No project mutation

UI

Where to run it

Use Diagnostics in the full-screen inspector, press Ctrl+G, or use Run Diagnostics from the compact Lua Module Studio settings.

Severity:
error   blocks a clean export
warning needs review
info    improves publishing quality
