Toolbar

Primary actions

Load and Save

Load selected files into the editor and save through the bounded safe buffer.

Validate and Dry Run

Validate manifest/script readiness and simulate discovered hooks without executing Lua.

Import and Export

Import latest ZIP exports with path traversal checks and export validated module ZIPs.

Sync Docs

Copy the local docs site to the public docs-only GitHub Pages repository and push updates.

Marketplace

Filter entries by tag/template/featured status, validate checksums, import local or remote examples, and export a pack manifest.

Visual Builder

Apply metadata presets, add events, permissions, settings, links, and preview scenarios without editing raw JSON.

History and Profiles

Snapshot projects, restore the latest snapshot, export profile bundles, and import validated profile setup ZIPs.

Preview Scenarios

Run dry-run previews with selected mock player, world, command args, setting ids, and setting values.

Dashboard and Assets

Run full readiness checks, list assets, import assets from bundles, and delete only with the asset armed toggle.

Dependencies and Publish Drafts

Add required/conflicting dependency metadata and generate validated marketplace package drafts.

Editor Tools

Find text, jump through the file, duplicate lines, comment/uncomment, format indentation, run diagnostics, insert autocomplete, and jump to manifest/settings.
