Toolbar

Primary actions

Load and Save

Load selected files into the editor and save through the bounded safe buffer.

Validate and Dry Run

Validate manifest/script readiness and simulate discovered hooks without executing Lua.

Import and Export

Import latest ZIP exports with path traversal checks and export validated module ZIPs.

Sync Docs

Copy the local docs site to the public docs-only GitHub Pages repository and push updates.

Marketplace

Cycle featured entries, validate checksums, import examples, and export a pack manifest.

Shortcuts

Keyboard workflow

The screen supports editor typing, caret movement, page scrolling, and common project actions. Escape leaves editor focus first, then closes the screen.
