Reports

Read exported verification results

Export Verification Report writes a machine-readable JSON file to clouse/lua-exports/lua-verification-report.json.

{
  "generatedAt": 1760000000000,
  "passed": 7,
  "failed": 0,
  "passedAll": true,
  "lines": [
    "PASS tokenizer parses identifiers",
    "PASS marketplace remote index validates hosted JSON"
  ]
}

Fields

How to interpret it

passed and failed are counts. passedAll is true only when every check succeeded. lines keeps the same readable PASS/FAIL entries shown in the Studio console.

passedAll: true
safe to continue authoring

passedAll: false
read FAIL lines first
fix before publishing
