Safety model

Validate before runtime

The current maker library focuses on authoring, validation, import/export, and dry-run previews. It deliberately avoids running untrusted Lua directly.

Import ZIP
  -> block path traversal
  -> enforce file count
  -> enforce byte limits
  -> require module.json
  -> validate entry script
  -> report unsafe tokens

Blocked patterns

Unsafe calls are reported

Token Reason Result
os.execute Can run host commands Warning in validation and dry-run
io.popen Can spawn host processes Warning in validation and dry-run
package.loadlib Can load native libraries Warning in validation and dry-run
dofile / loadfile Can bypass project entry checks Warning in validation and dry-run
