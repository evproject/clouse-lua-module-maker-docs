Remote marketplace imports download public ZIP packages only from allowlisted HTTPS docs hosts, verify size and checksum, then reuse the same ZIP and manifest safety checks as local imports.

Checks

Import gates

Host allowlist

Only evproject.github.io is accepted for current public marketplace packages.

Size cap

Downloads stop once the package exceeds the configured 8 MB maximum.

Checksum

The ZIP must match the marketplace entry's SHA-256 hash before extraction.

ZIP safety

Path traversal, missing manifests, oversized projects, and too many files are rejected.
