Studio editor

Build scripts without commands

The editor buffer powers both the settings actions and the full-screen Lua Studio. It loads module files, inserts generated snippets, saves them back to disk, and previews hook behavior before export.

Actions

What each button does

Load File

Reads the selected file into a bounded UTF-8 buffer and prints a short preview in chat.

Insert Snippet

Adds a generated Lua snippet to main.lua while preserving the final return module.

Save Buffer

Writes the buffer back to disk and validates JSON when saving manifests or settings.

Dry Run Preview

Scans hooks and reports the mock calls that would happen without executing Lua code.

Project operations

Duplicate, rename, delete
