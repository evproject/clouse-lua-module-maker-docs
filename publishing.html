Public docs

Publish with GitHub Pages

The docs folder is a standalone static site. A separate docs-only repository can publish it publicly without exposing the full client source, and Lua Module Studio can sync it from the UI.

docs/
  index.html
  editor.html
  safety.html
  publishing.html
  styles.css
  script.js
  examples/

Workflow

Pages deployment

The included workflow uploads docs/ as a Pages artifact and deploys it through GitHub Actions. The public docs-only repository serves the same files from its root and can be updated by Sync Docs.

actions/configure-pages@v5
actions/upload-pages-artifact@v3
actions/deploy-pages@v4
