Runtime

Preview hooks safely

Dry Run Preview uses a custom tokenizer, hook parser, and tiny evaluator for generated Lua modules. It executes safe hooks against mocked data and records what would happen.

on_load(ctx)
on_tick(ctx) x3
on_render_hud(ctx, draw)
on_command(ctx, {"status"})
on_settings_changed(ctx, "debug", true)
on_unload(ctx)

Supported subset

Enough for authoring previews

Literals and tables

Strings, numbers, booleans, nil, simple table literals, and module fields.

Control flow

Local variables, assignments, simple functions, return, and if/then/end blocks.

Expressions

String concatenation, equality, arithmetic, modulo, not, or, tostring, and math.floor.

Safe ctx calls

ctx.log, ctx.setting, ctx.player, ctx.world, import_json, export_json, and draw.text.

Blocked

No host access

The runtime rejects unsafe tokens before evaluation. It does not expose OS, file, network, reflection, process, native library, debug, package, require, io, or unrestricted os access.

io.popen
